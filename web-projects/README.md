# 🌐 Proyectos Web QA

Este directorio agrupa proyectos de pruebas funcionales y automatizadas sobre aplicaciones web de ejemplo.  
Cada proyecto incluye su propio plan de pruebas, casos, reportes y scripts de automatización.

---

## 📌 Proyectos incluidos

### [SauceDemo – E-commerce](./SauceDemo)
- **Descripción:** Pruebas funcionales y automatizadas sobre un sitio de compras en línea.  
- **Alcance:** login, catálogo de productos, carrito, checkout, logout, APIs REST.  
- **Artefactos principales:**  
  - `Test_Plan.md` → Estrategia y alcance de pruebas.  
  - `Risk_Matrix.md` → Identificación de riesgos críticos.  
  - `Traceability_Matrix.md` → Cobertura de requisitos ↔ casos de prueba.  
  - `Test_Cases/` → Casos organizados por módulo.  
  - `Bug_Reports/` → Registro de defectos.  
  - `Automation/Cypress/` → Scripts automatizados.  
  - `Reports/Execution_Summary.md` → Informe de resultados.  

---

### 2. HomeBanking Demo – Aplicación bancaria
- **Descripción:** Pruebas sobre una aplicación web tipo bancaria disponible en [HomeBanking Demo](https://homebanking-demo-tests.netlify.app/).  
- **Alcance:** login seguro, gestión de cuentas, transferencias, validación de saldos, historial de transacciones.  
- **Artefactos principales:**  
  - `Test_Plan.md` → Estrategia de pruebas para flujos bancarios.  
  - `Risk_Matrix.md` → Riesgos críticos (seguridad, integridad de datos).  
  - `Traceability_Matrix.md` → Requisitos ↔ casos de prueba.  
  - `Test_Cases/` → Casos de prueba por módulo (login, transferencias, reportes).  
  - `Bug_Reports/` → Registro de defectos encontrados.  
  - `Automation/Cypress/` → Scripts automatizados de login y transferencias.  
  - `Reports/Execution_Summary.md` → Informe de ejecución.  

---

## 🎯 Objetivo
Mostrar buenas prácticas de QA en proyectos web, incluyendo:  
- Estrategia de pruebas documentada.  
- Cobertura de requisitos mediante trazabilidad.  
- Priorización de riesgos.  
- Ejecución manual y automatizada.  
- Reportes claros y reproducibles.
